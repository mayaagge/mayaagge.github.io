SET

A browser version of the card game I built in NetLogo with Sofia Pisareva. Find three cards that make a SET before the timer runs out. Five correct sets wins.

Score0
Time left15
How to play
  • Each card has a shape (diamond, squiggle, oval), a color (red, blue, yellow), and a number (1, 2, 3).
  • Click three cards. They make a SET if, for each of the three features, the cards are either all the same or all different.
  • You have 15 seconds per round. A wrong guess or running out of time loses the game. Reach 5 points to win.
  • If a deal has no SET at all, the game says "No SET" and deals again.
