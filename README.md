# Maya Agge

My project portfolio: **[mayaagge.github.io](https://mayaagge.github.io/)**

I'm a first-year at the University of Chicago, interested in where markets, data and modeling meet. This site collects my projects in one place, with links to play, read or run each one.

## Featured project: One Trade

**[Play it](https://mayaagge.github.io/one-trade/)** · **[Code and research](https://github.com/mayaagge/one-trade)**

A free browser game that teaches diversification with live market data and pretend money. You build a portfolio, guess how many independent bets it makes, and see the answer from real price history. I pre-registered three hypotheses before downloading any prices and published every verdict, including the two that went against me.

## Also on the site

## How it's built

Plain HTML, CSS and JavaScript, with no framework or build step, hosted free on GitHub Pages. The page follows your device's light or dark mode.

| Path | What's in it |
| --- | --- |
| `index.html` | The portfolio page |
| `play/` | Browser versions of the games and the motor simulation |
| `papers/` | Research and modeling papers (PDF) |

To run it locally, clone the repo and open `index.html`, or run `python3 -m http.server 8000` and go to `localhost:8000`.
